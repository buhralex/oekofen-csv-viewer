<decisions_made>

- Settings export is NOT JSON — it's a proprietary formatted .txt file with sections and allowed values in brackets. Needs custom parser (Phase 8).
- CSV usage data comes from heater API or manual upload only — NOT from .save ZIP. .save ZIP is irrelevant for data accumulation.
- .save ZIP's .txt settings file IS the baseline source (BASE-01).
- Öko Modus explicitly excluded from AI recommendations — community feedback says it underperforms in practice.
- AI "trained" means expert knowledge baked into system prompt (not fine-tuning).
- Both Ollama (local) and Claude API (cloud) supported — user configures in Settings.
- AI receives aggregated stats + parsed settings only — raw CSV rows never sent.
- Storage: IndexedDB (not localStorage) for multi-day CSV history — volume requires it.
- Analysis panel is a full-screen separate view (not a tab or side panel).
- Phase numbering continues from v1.1: v1.2 starts at phase 7.
