**A. Fix cursor and select opts in createChart() opts object:**

Replace:
```javascript
cursor: {
  show: false,  // Phase 3 adds crosshair and tooltip
},

select: { show: false },  // Phase 3 adds drag-to-zoom selection
```

With:
```javascript
cursor: {
  show: true,
  x: true,
  y: false,
  drag: {
    setScale: true,   // native drag-to-zoom — calls setScale('x') on mouseup
    x: true,
    y: false,
    dist: 3,          // minimum drag distance in px before zoom activates (prevents mis-clicks)
  },
},

select: { show: true },   // shows selection rectangle during drag
```

**B. Add plugins array and hooks to the opts object (before the closing brace of opts):**

After the `padding` line, add:
```javascript
hooks: {
  setScale: [(u, scaleKey) => {
    if (scaleKey === 'x') {
      const min = u.scales.x.min;
      const max = u.scales.x.max;
      AppState.zoomRange = { min, max };
      if (AppState.onZoomChange) AppState.onZoomChange(min, max);
      updateResetButtonVisibility(u);
    }
  }],
},
```

**C. Add the `updateResetButtonVisibility` function** above `createChart()`:
```javascript
function updateResetButtonVisibility(u) {
  const btn = document.getElementById('reset-zoom-btn');
  if (!btn || !u) return;
  const dataMin = u.data[0][0];
  const dataMax = u.data[0][u.data[0].length - 1];
  const min = u.scales.x.min;
  const max = u.scales.x.max;
  // 1-second tolerance to avoid float rounding causing button to show at full range
  const isFullRange = (min <= dataMin + 1) && (max >= dataMax - 1);
  btn.style.display = isFullRange ? 'none' : '';
}
```

**D. After `AppState.chart = new uPlot(opts, data, container);`, add reset wiring:**
```javascript
// Wire reset button
document.getElementById('reset-zoom-btn').addEventListener('click', () => {
  if (AppState.chart) AppState.chart.setScale('x', { min: null, max: null });
});

// Wire double-click reset (uPlot v1.6.x has native dblclick reset on .over —
// this listener is an explicit backup and ensures consistent behavior)
AppState.chart.over.addEventListener('dblclick', () => {
  AppState.chart.setScale('x', { min: null, max: null });
});

// Initialize reset button visibility (hidden at full range on load)
updateResetButtonVisibility(AppState.chart);
```

**E. Also update `destroyChart()` to reset AppState.zoomRange:**
After `AppState.chart = null;` add:
```javascript
AppState.zoomRange = null;
AppState.onZoomChange = null;
```

This ensures stale minimap callbacks don't fire after a new file is loaded.
