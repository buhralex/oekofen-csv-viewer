Replace with:
```javascript
async function fetchCsv(command) {
  // CONN-03: Rate-limit guard — 2500ms minimum between fetches
  const now = Date.now();
  if (_lastFetchAt > 0 && (now - _lastFetchAt) < 2500) {
    showToast('Please wait before downloading again.', 'warning', 3000);
    return;
  }
  // Write timestamp when fetch actually starts (not when response arrives)
  _lastFetchAt = Date.now();

  setFetchButtonState('loading');

  // Route through local proxy — server.py fetches the heater server-side, bypassing CORS.
  // Direct browser fetch to the OekoFEN heater is permanently blocked (no Access-Control-Allow-Origin header).
  const heaterUrl = 'http://' + _settings.ip + ':' + _settings.port + '/' + _settings.password + '/' + command;
  const url = '/proxy?url=' + encodeURIComponent(heaterUrl);

  try {
    // ERR-02: 10-second timeout via AbortSignal.timeout (Chrome 103+, FF 100+, Safari 16+)
```

- Added comment explaining why proxy is used.
- All other logic (rate-limit guard, `_lastFetchAt = Date.now()`, `setFetchButtonState('loading')`, try/catch/finally) is unchanged.
