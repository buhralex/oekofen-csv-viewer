Extend openSettingsModal() in index.html to include a baseline section below the API Password field and above the footer.

The baseline section is a visually separated block inside the modal body with:
- A separator line (border-top)
- A label "Heater Settings Baseline"
- A status line showing either the loaded baseline info or "No baseline loaded"
- A "Load Settings File" button that opens a hidden file input accepting .txt

**Implementation inside openSettingsModal()** — add after the body.appendChild(pwWrap) line and before dialog.appendChild(body):

```js
// ── Baseline section ─────────────────────────────────────────────
const baselineSep = document.createElement('div');
baselineSep.style.cssText = 'border-top:1px solid var(--sep); margin:4px 0 12px;';
body.appendChild(baselineSep);

const baselineLabel = document.createElement('div');
baselineLabel.style.cssText = 'font-size:12px; font-weight:500; color:var(--text-2); margin-bottom:6px;';
baselineLabel.textContent = 'Heater Settings Baseline';
body.appendChild(baselineLabel);

const baselineStatusEl = document.createElement('div');
baselineStatusEl.id = 'baseline-modal-status';
baselineStatusEl.style.cssText = 'font-size:12px; color:var(--text-3); margin-bottom:8px;';
baselineStatusEl.textContent = _baseline
  ? '\u2713 ' + (_baseline.filename || 'settings.txt') + ' \u2014 ' + _baseline.sectionCount + ' sections'
  : 'No baseline loaded';
body.appendChild(baselineStatusEl);

const baselineLoadBtn = document.createElement('button');
baselineLoadBtn.textContent = 'Load Settings File';
baselineLoadBtn.style.cssText = [
  'padding:6px 14px; border-radius:var(--r-sm); border:1px solid var(--sep-strong);',
  'background:none; color:var(--text-2); font-size:12px; font-family:var(--font);',
  'cursor:pointer;',
].join('');
body.appendChild(baselineLoadBtn);

const baselineModalErrEl = document.createElement('div');
baselineModalErrEl.style.cssText = 'font-size:12px; color:#DC2626; margin-top:6px; min-height:14px;';
body.appendChild(baselineModalErrEl);

// Hidden file input for .txt — clicking the button triggers it
const baselineModalFileInput = document.createElement('input');
baselineModalFileInput.type = 'file';
baselineModalFileInput.accept = '.txt';
baselineModalFileInput.style.display = 'none';
body.appendChild(baselineModalFileInput);

baselineLoadBtn.addEventListener('click', () => baselineModalFileInput.click());

baselineModalFileInput.addEventListener('change', (e) => {
  const file = e.target.files[0];
  if (!file) return;
  const reader = new FileReader();
  reader.onload = (ev) => {
    try {
      const parsed = parseBaselineTxt(ev.target.result);
      parsed.filename = file.name;
      saveBaseline(parsed);
      baselineStatusEl.style.color = 'var(--text-2)';
      baselineStatusEl.textContent = '\u2713 ' + file.name + ' \u2014 ' + parsed.sectionCount + ' sections';
      baselineModalErrEl.textContent = '';
    } catch (err) {
      baselineModalErrEl.textContent = err.message;
      baselineModalFileInput.value = '';
    }
  };
  reader.readAsText(file, 'utf-8');
});
```

The baseline section sits between the password field and the footer separator — no changes to footer buttons or other modal behavior. `_baseline` is read at modal-open time to show current status; status updates live within the modal after a successful load without requiring a modal reopen.
