  <action>
Add to server.py (after existing imports and constants, before load_schedule_settings):

1. Import sqlite3 at the top of the file.

2. Define STATS_DB_PATH = os.path.join(SCRIPT_DIR, 'stats.db').

3. Write open_stats_db() function:
   - Creates stats.db if missing
   - Executes CREATE TABLE IF NOT EXISTS daily_stats with columns:
     date TEXT PRIMARY KEY,
     starts INTEGER,
     runtime_minutes REAL,
     pellet_kg REAL,          -- NULL when no counter column found
     avg_outdoor_temp REAL,   -- NULL when no AT column found
     flow_return_delta REAL,  -- NULL when no flow or return column found
     degree_day_consumption REAL,  -- NULL when pellet_kg or avg_outdoor_temp is NULL
     row_count INTEGER,
     hours_covered REAL,
     is_partial INTEGER,      -- 1 if hours_covered < 20, else 0
     computed_at INTEGER      -- Unix ms timestamp
   - Returns the connection

4. Write detect_columns(headers) function — auto-detects column names from CSV header list:
   Returns a dict:
   - 'burner': first header matching case-insensitive 'BR' exactly, or None
   - 'runtime': first header matching case-insensitive 'L_runtime' exactly, or None
   - 'pellet': first header where name part (before '[') matches /^PE1.*cnt|^PE1.*verbrauch|^PE1.*pellet|^L_pellet/i, or None
   - 'outdoor_temp': first header where name part matches /^AT$/ (case-sensitive), or None
   - 'flow_temp': first header where name part matches /^HK1.*VL/, or None
   - 'return_temp': first header where name part matches /^HK1.*RT/, or None

   Name-part extraction: split on '[' and take first part, strip whitespace.
   All regex matching is case-insensitive except AT (must be exact uppercase).
   Log detected columns: print(f'[stats] columns detected: {detected}')

5. Write parse_german_float(s) helper:
   - Replace comma with dot, strip whitespace, return float(s) on success, None on failure

6. Write compute_day_stats(csv_string, date) function:
   - Parse CSV: split lines, first non-empty line = headers (split on ';'), strip each header.
   - Call detect_columns(headers) to get column indices.
   - Parse all data rows: skip empty lines and header row; store each row as list of raw strings.
   - Compute row_count = number of valid data rows.
   - Compute hours_covered: parse Datum and Zeit columns to get first and last timestamps; hours = (last_ts - first_ts) / 3600. If < 2 rows, hours_covered = 0.
   - is_partial = 1 if hours_covered < 20 else 0.
   - Burner starts: if 'burner' column detected — iterate rows, count transitions from 0 to 1 (rising edge). Compare float(row[i-1]) == 0 and float(row[i]) == 1. Skip row if parse fails. If no burner column: starts = None.
   - Runtime minutes: if 'runtime' column — last_val minus first_val (parse_german_float). Clamp to 0 if negative. If no column: runtime_minutes = None.
   - Pellet kg: if 'pellet' column — last_val minus first_val. Clamp to 0. If no column: pellet_kg = None.
   - Avg outdoor temp: if 'outdoor_temp' column — mean of all non-None parse_german_float values. If no column or all None: avg_outdoor_temp = None.
   - Flow/return delta: if both 'flow_temp' and 'return_temp' detected — compute per-row (flow - return) for all rows where both parse successfully, then mean. If either column missing: flow_return_delta = None.
   - Degree-day consumption: if pellet_kg is not None and avg_outdoor_temp is not None and avg_outdoor_temp < 18: pellet_kg / (18.0 - avg_outdoor_temp). Otherwise None.
   - Return dict with all computed fields + date + computed_at = int(time.time() * 1000).
   - On any exception: print warning, return None.

   - List all YYYYMMDD.csv files in HISTORY_DIR
   - Open stats DB; query existing dates: SELECT date FROM daily_stats
   - For each CSV file whose date is not in DB: call compute_and_store_stats(date)
   - print(f'[stats] Backfill complete — {n} new days computed')

3. Write get_all_stats() function:
   - Opens stats DB, SELECT * FROM daily_stats ORDER BY date ASC
   - Computes multi-day trend (linear regression on starts over time):
     - Use only complete days (is_partial=0) where starts is not NULL
     - If fewer than 3 complete days: trend = {'direction': None, 'slope': None, 'label': 'N/A — need 3+ complete days'}
     - Else: compute slope via least-squares regression (x = day index 0,1,2..., y = starts)
       slope = (n*sum_xy - sum_x*sum_y) / (n*sum_x2 - sum_x**2)
       direction = 'up' if slope > 0.05 else ('down' if slope < -0.05 else 'stable')
       label = f'↑ +{slope:.2f} starts/day' if up, f'↓ {slope:.2f} starts/day' if down, '→ stable'
       (0.05 threshold is Claude's discretion — small slope = stable)
   - Returns dict: { 'days': [...row dicts...], 'trend': trend_dict, 'total_days': N, 'complete_days': M }

4. Add GET /stats route to Handler.do_GET():
   - Add before the existing `if parsed.path == '/proxy':` block
   - if parsed.path == '/stats':
       stats = get_all_stats()
       body = json.dumps(stats, default=lambda x: None).encode('utf-8')
       send 200 with Content-Type application/json, Access-Control-Allow-Origin: *, Content-Length
       return

   - Call compute_and_store_stats(date_str)

6. In the __main__ block: after the server socket is set up but before server.serve_forever(), call backfill_stats() — this runs synchronously at startup so stats are ready before first request. Wrap in try/except so a corrupt CSV never prevents server startup.

IMPORTANT: Use sqlite3 connections in a way that is thread-safe — open a new connection per function call (do not share connections across threads).
